# Bernard G. Briola - Portfolio

A static portfolio site: plain HTML, CSS and JavaScript. No build step.

    index.html        page content
    css/style.css     styles (light/dark themes, high-contrast and reduced-motion modes)
    img/og.png        preview image shown when the link is shared
    js/script.js      theme and display options, estimate calculator, Manila clock, scroll effects

## Put it online with GitHub Pages
1. Create a public repository named `Bernard-26.github.io`.
2. Upload everything in this folder (keep the `css` and `js` folders).
3. Settings > Pages > Deploy from a branch > `main` / root > Save.
4. Open https://bernard-26.github.io

## Edit
- Prices and extras: the `<option value>` and `class="e-add"` values in index.html.
- Email address: search for the address in index.html and js/script.js.
- Colors: the variables at the top of css/style.css.
